路演脚本（上台照念）
  1. 钩子（10 秒）：我们每天都在立目标，但很少有人能说清「今天做的这件事，到底有没有帮到目标」。
  2. 定位（10 秒）：复盘通把「每日进步五问」变成打卡——五问填完，它还你一张「每日复盘卡」。
  3. 现场演示（20 秒）：一屏五问 → 推进度判定 → 复盘卡 → 下载 PNG → 确认保存 → 打卡墙与月热力图。
  4. 差异化（10 秒）：不是记流水账，而是计划 vs 实际 vs 目标的三方对照；月热力图一眼看出有没有走偏。
  5. 收尾（10 秒）：它不生产漂亮话，只帮你把「今天到底推进了什么」说清楚。

演示小抄：① 一键填入示例五问 → 开始复盘；② 切一次主题；③ 下载卡片；④ 确认并保存 → 看打卡墙与月热力图。
