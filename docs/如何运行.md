# 复盘通 ReviewPal · 运行须知

## 一、运行需要什么（只需要一样）
- 一台电脑（Windows / macOS / Linux 均可）+ 安装 **Node.js**。
  - **版本：建议 Node v24**（本机为 v24.21.0）；**最低 v22.5**（项目用了 Node 内置的 `node:sqlite`）。低于 v22.5 请升级。
- **不需要**：`npm install`、数据库软件、联网。（默认以 **Mock** 模式运行；要用**真实模型**才需要联网 + API Key。）

## 二、Windows 上运行（自己或别人电脑都一样）
1. 装 Node.js：官网 https://nodejs.org 下载安装（安装时勾选 **Add to PATH**）。
   - 验证：打开 cmd，输入 `node -v`，能显示版本号即可。
2. 拿到项目：解压 `复盘通_代码提交_V1.18.zip`（或直接拷贝整个文件夹）。
3. **双击 `start.bat`** → 弹出黑窗口（别关，它就是后端）。
4. 浏览器打开 **http://localhost:8787** 。
- 停止：关掉黑窗口，或按 `Ctrl + C`。

## 三、macOS / Linux 上运行
1. 安装 Node.js（同上）。
2. 终端进入项目目录：
   ```
   node server/index.js
   ```
   （或 `bash start.sh`）
3. 浏览器打开 http://localhost:8787 。

## 四、常见问题
- **双击 start.bat 一闪而过 / 提示没找到 node**：Node 没装或没加进 PATH → 装好后重开；或在项目目录用命令行 `node server/index.js` 看报错。
- **报 `node:sqlite` 相关错误**：Node 版本太低 → 升级到 v24。
- **端口 8787 被占用**：命令行先 `set PORT=8899`（mac/linux 用 `export PORT=8899`）再 `node server/index.js`，然后开 http://localhost:8899 。
- **别双击 `web/index.html`**：那没有后端，必须从 `http://localhost:8787` 打开。
- **真实模型报 `fetch failed`**：那台电脑没外网 / DNS 不通 → 先用「用 Mock 数据演示」。
- **数据在哪**：项目目录下 `data/reviewpal.db`（运行时自动生成）。

## 五、让别人也能访问（可选）
- 同一局域网：对方用 `http://<你的IP>:8787` 打开（需在系统防火墙放行 8787）。
- 公网访问：按 `docs/复盘通_公网部署指南.md` 部署到一台有 Node 的服务器。
